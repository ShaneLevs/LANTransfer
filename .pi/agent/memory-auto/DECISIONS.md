LANTransfer（uTools 插件，/Users/shanelevs/Documents/GitHub/LANTransfer）：局域网文件/剪贴板互传。架构：HTTP 服务跑在 bridge/preload.js 内（纯 node:http，无第三方依赖，CommonJS，SDK 依据 preload 可用 Node 原生模块）；bridge/lib/{store,server,util}.js + src/（React + shadcn 主界面，4 个 Tab：服务/分享/接收/剪贴板）+ lan/（同一 Vite 工程的第二入口=网页端）+ scripts/copy-bridge.mjs（build 时把 bridge 拷进 dist，dist 即 uTools 插件目录，改代码必须重跑 npm run build）。实时同步用 SSE /api/events 广播 changed，网页端收到后重取 /api/state。存储：接收目录下 shared/（我分享）、uploads/（别人上传）、clipboard/ 三个子目录，配置与元数据 state.json 放 utools.getPluginLocalDataPath()。已定决策：无密码；剪贴板保留天数可配、默认 7 天；按类型分子目录；复制走 HTTP + 兜底。安全约定：/api/state 必须剥离本地绝对路径（file 字段不能下发）、下载强制 attachment + nosniff、仅图片/纯文本/音视频允许内联预览（防上传 HTML 的 XSS）、文件名清洗 + 重名加序号、路径穿越校验。验证方式：集成测试直接跑 dist/lib（node），主界面用注入 mock window.services 的 dist/mock.html 在浏览器烟测（uTools 真机无法本地启动）。.npmrc 用于绕过用户全局 npm 的 allow-scripts 策略。
