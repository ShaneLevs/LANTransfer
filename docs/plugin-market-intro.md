# 共享桌面 · 插件市场介绍文案（v0.3.0）

> 用途：粘贴到 uTools 插件应用市场的「介绍」栏。下文分三部分：列表页短简介、详情页长介绍、关键词与使用提示。

## 一、列表页短简介

**共享桌面** —— 电脑开一个网页，同一 Wi‑Fi 下的手机、平板、其他电脑打开地址，就能共用一块**共享桌面**：文字、验证码、截图、文件都是桌面上的卡片，随手拖动摆放。不走云端、不装客户端、没有账号。

命令词：`局域网传输` / `共享桌面` / `局域网分享` / `lan transfer`

## 它能做什么

**一块可随意拖排的桌面（电脑浏览器）**

- 文字、图片、文件都是桌面上的卡片，鼠标拖到任意位置，位置会同步给所有设备
- 滚轮 / 触控板捏合缩放（20%–300%），拖空白处平移，一键「排布」恢复网格
- 顶部就一个「新建卡片」按钮：弹窗里可以输入/粘贴文字、Ctrl / Cmd + V 粘图片、选择或拖入文件
- 不弹窗也行：直接把文字、截图粘到桌面上，或把文件从硬盘拖进来，自动成为卡片
- 点文字或图片卡片可以放大查看（文字看全文，图片看大图）

**手机 / 平板打开（列表视图）**

- 复制的验证码、地址、长文本粘贴或点「新建卡片」发出去，电脑上点一下就能复制使用
- 每张卡片顶部一行基础信息：上传人（主机登录用户名，其它设备显示访客）、来源 IP、时间、类型
- 卡片按钮按类型给：文字＝复制，文件＝下载，图片＝两者都有，再加「复制链接」

**插件端（uTools 窗口）**

- 「设置」页：启动 / 停止、复制地址、监听网卡、端口、存储目录、保留天数
- 「共享桌面」页：一个「新建卡片」弹窗搞定输入文字 / 粘贴图片 / 选文件（弹窗不占列表空间），也可以直接在窗口里 Ctrl / Cmd + V 粘图
- 每张卡片：基础信息（上传人 / IP / 时间 / 类型）+ 内容预览 + 复制（文字、图片）、下载（图片、文件）、复制链接、删除（进系统回收站）
- 「复制链接」得到的是单卡片链接（`?card=…`），拿到链接的人只看到这一张卡片，内容全部展开，同样可以复制 / 下载

**快捷入口，少点几下**

- 选中文件 → `局域网共享文件`（直接放到桌面）
- 选中图片 → `局域网共享图片`
- 选中文字 → `局域网共享文字`
- 完成后会弹一条系统通知，不用切窗口确认

## 为什么用它

- **不走云端**：只有一条局域网 HTTP 连接，没有账号、没有登录、没有上传到服务器的环节，断网也照常可用
- **对方零安装**：其他设备只需要一个浏览器
- **内容留在自己硬盘**：桌面上的文字、图片、文件都保存在存储目录的 `clipboard` 子目录，删条目会进系统回收站，随时可以自己清理
- **可控**：监听网卡、端口、存储目录、保留天数（默认 7 天，桌面最多 300 条）都能自己设置，还能开启插件加载后自动启动服务
- **实时同步**：任何一端放了新内容或挪动了卡片，其他打开网页的设备立刻更新

## 上手三步

1. `局域网传输` 打开插件，在「设置」页点「启动服务」
2. 点「复制地址」，把它发到手机（或直接在电脑浏览器打开）
3. 电脑浏览器打开 = 可随意拖排的桌面；手机打开 = 列表，粘贴、发送、复制都够用

## 首次使用说明

- 请在插件「设置」页按需修改「存储目录」（默认是「下载 / LANTransfer」），所有内容都保存在这里
- 如果启动失败提示端口被占用，换成 1024–65535 之间的其他端口即可，运行中的服务会自动重启
- 电脑有多个网卡（有线 / 无线 / 虚拟机）时，在「监听地址」里选择手机所在的那张网卡
- 服务只在本机运行，关闭插件窗口不影响网页端使用，但退出 uTools 或停止服务后地址会失效

## 能力边界

- 暂不支持文件夹（选中文件夹会被跳过）
- 网页端不做密码校验：同一局域网内知道地址的人都能访问，请只在可信网络（家里 Wi‑Fi、公司内网）里使用
- 需要设备在同一局域网；路由器开了「AP 隔离」或设备在不同网段会连不上
- 不会自动读写你的系统剪贴板：内容都要你自己粘贴、输入或选文件
- 网页端不提供删除（只能在插件端删），避免误删别人的内容；可拖拽排布的桌面视图面向电脑浏览器，手机 / 平板为列表
