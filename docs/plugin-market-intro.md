# 局域网传输 · 插件市场介绍文案（v0.1.0）

> 用途：粘贴到 uTools 插件应用市场的「介绍」栏。下文分三部分：列表页短简介、详情页长介绍、关键词与使用提示。

## 一、列表页短简介

**局域网传输** —— 电脑开一个网页，同一个 Wi‑Fi 下的手机、平板、其他电脑打开地址就能互传文件、图片和文字。不走云端、不装客户端、没有账号，文件只在这台电脑和局域网里流动。

命令词：`局域网传输` / `局域网分享` / `lan transfer`

````markdown
## 一个网页，把局域网内的设备连起来

局域网传输会在你的电脑上启动一个轻量网页服务，同一个 Wi‑Fi 下的任何设备用浏览器打开这个地址，就能和这台电脑互传内容——不用插数据线、不用扫码登录、不用把文件传给任何第三方服务器。

```

## 它能做什么

**1. 电脑 → 手机 / 其他电脑：分享文件**

- 选中文件后直接调用命令词「局域网分享文件」，或按关键词打开插件点「选择文件分享」
- 手机打开地址，在「文件」页点一下就能下载，也可以复制单条文件的直链
- 分享的文件会复制到接收目录，原文件不受影响

**2. 手机 / 其他电脑 → 电脑：接收文件**

- 网页端「上传」页支持点击选择、拖拽、多选，并显示每个文件的传输进度
- 上传的文件自动落到接收目录的 `uploads` 子目录，插件里点「打开」或「显示」即可处理

**3. 多设备共享剪贴板（最常用的场景）**

- 手机上复制的验证码、地址、长文本，粘贴到网页端「剪贴板」页发出去，电脑上直接复制使用
- 电脑上点「分享系统剪贴板」，会自动识别当前剪贴板里的文字、图片或文件并发到共享剪贴板
- 截图、图片可以直接 Ctrl / Cmd + V 粘贴（插件窗口和网页端都支持）
- 所有打开网页的设备看到的是同一份内容，谁发的、什么时候发的都有标注
- 超过保留天数（默认 7 天，可设置 1–365 天）的内容会自动清理，剪贴板最多保留 300 条

**4. 快捷入口，少点几下**

- 选中文件 → `局域网分享文件`
- 选中图片 → `局域网共享图片`（直接进共享剪贴板）
- 选中文字 → `局域网共享文字`
- 分享完成后会弹一条通知，不用切窗口确认

## 为什么用它

- **不走云端**：只有一条局域网 HTTP 连接，没有账号、没有登录、没有上传到服务器的环节，断网也照常传
- **对方零安装**：接收方只需要一个浏览器，手机、平板、公司电脑都能用
- **内容留在自己硬盘**：分享、上传、剪贴板分别保存在接收目录的 `shared`、`uploads`、`clipboard` 子目录，删条目会进系统回收站，随时可以自己清理
- **可控**：监听网卡、端口、接收目录、剪贴板保留天数都能自己设置，还能开启插件加载后自动启动服务

## 上手三步

1. `局域网传输` 打开插件，在「服务」页点「启动服务」
2. 点「复制地址」，把它发到手机（或直接在电脑浏览器打开）
3. 手机上打开这个地址：要文件去「文件」，要给电脑传东西去「上传」，要跨设备复制粘贴去「剪贴板」

## 首次使用说明

- 请在插件「服务」页按需修改「接收目录」（默认是「下载 / LANTransfer」），所有内容都保存在这里
- 如果启动失败提示端口被占用，换成 1024–65535 之间的其他端口即可，运行中的服务会自动重启
- 电脑有多个网卡（有线 / 无线 / 虚拟机）时，可以在「监听地址」里选择手机所在的那张网卡
- 服务只在本机运行，关闭插件窗口不影响正在进行的传输，但退出 uTools 或停止服务后地址会失效

## 首版能力边界

- 暂不支持分享文件夹（选中文件夹会被跳过）
- 网页端不做密码校验：同一局域网内知道地址的人都能访问，请只在可信网络（家里的 Wi‑Fi、公司内网）里使用
- 需要设备在同一局域网；如果路由器开了「AP 隔离」或设备在不同网段，会连接不上
- 这里的「共享剪贴板」是局域网内的共享列表，不会自动读写你的系统剪贴板，需要点一下「分享系统剪贴板」或「复制」
````
